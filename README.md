# Armazenamento de Atividades

## Sobre o projeto

O **Armazenamento de Atividades** é um sistema web desenvolvido com o objetivo de facilitar a organização e o armazenamento de atividades e trabalhos realizados durante a graduação.

A aplicação permite organizar os arquivos acadêmicos por meio de uma estrutura hierárquica:

**Período → Matéria → Atividade/Trabalho → Arquivos**

Dessa forma, o usuário consegue separar seus materiais por período e matéria, mantendo atividades, trabalhos e seus respectivos arquivos organizados em um único lugar.

O projeto está sendo desenvolvido utilizando **Python e Django**, com foco no aprendizado de desenvolvimento Back-End e na construção de aplicações web.

## Objetivos e aprendizados

Durante o desenvolvimento deste projeto, pretendo aprofundar meus conhecimentos em:

- **Python:** aprimoramento da lógica de programação e aplicação dos conceitos da linguagem.
- **Django:** compreensão da arquitetura MVT, criação de views, URLs, templates e formulários.
- **Banco de dados:** modelagem de dados, relacionamentos entre tabelas e operações CRUD.
- **ORM do Django:** manipulação de dados utilizando models e consultas ao banco de dados.
- **HTML e CSS:** construção e estilização de interfaces web.
- **Manipulação de arquivos:** implementação de funcionalidades para envio, armazenamento e acesso a arquivos.
- **Validação de dados:** aplicação de regras para garantir a integridade das informações.
- **Organização de código:** estruturação de projetos e boas práticas de desenvolvimento.

Além de desenvolver uma aplicação funcional, o projeto tem como objetivo fortalecer minha capacidade de planejar, implementar e resolver problemas durante a construção de um sistema do zero.
